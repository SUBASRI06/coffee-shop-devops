# Coffee Shop DevOps Project ☕

## Overview
This is a simple coffee shop web application deployed using Docker and Nginx.

## Technologies Used
- HTML, CSS
- Docker
- Nginx
- GitHub

## Project Workflow
Local Machine → Docker → GitHub

## How to Run
docker build -t coffee-shop .
docker run -d -p 8080:80 coffee-shop

## Result
Application runs on:
http://localhost:8080
